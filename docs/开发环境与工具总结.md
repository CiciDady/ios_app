# 开发环境与工具总结（ios_app）

> 本文档总结了针对本项目（计划做手机 App）的开发环境分析结论，涵盖两套环境：
> **① Cloud Agent 云端服务器（当前 Linux 环境，做 Android 部分）** 和
> **② 本地 Mac（Android + iOS 都能做）**，并附上工具、费用、使用方式，方便后期查阅。

---

## 0. 结论速览（TL;DR）

- **iOS 原生开发必须用 Mac + Xcode**；当前 Cloud Agent 是 Linux，没法编译/运行 iOS。
- **Android 可以在 Linux 云端开发**，但**云端没有 `/dev/kvm`，跑不了 Android 模拟器**，所以云端无法把原生 Android 界面真正跑起来演示。
- **推荐用 Expo / React Native**：一套代码同时出 Android + iOS，且能在云端用**网页预览**跑起来演示；以后在 Mac 上 Android/iOS 模拟器、真机都能直接用。
- **费用**：Expo 开发全程免费；只有「用 EAS 云端打包超额」或「正式上架商店」才可能花钱。
- **Token**：下载/安装工具本身不花 token；花的是「AI agent 运行、读命令输出、来回处理」的模型用量。

## 1. 两种技术路线对比

| 能力 | 原生 Android (Kotlin) | 原生 iOS (Swift) | **Expo / React Native（推荐）** |
|------|----------------------|------------------|-------------------------------|

| 在云端**跑起来并录屏演示** | ❌（无模拟器）| ❌ | ✅（`expo start --web` 网页预览）|

| 出 iOS 安装包 | —— | ✅（需 Mac）| ✅（EAS 云端，可不用 Mac）|
| 语言 | Kotlin/Java | Swift | TypeScript / JavaScript |

## 2. ① Cloud Agent 云端服务器（Android 部分）

### 2.1 当前环境已具备的工具

| 工具 | 状态 | 版本 |
|------|------|------|
| Java (JDK) | ✅ 已装 | OpenJDK 21 |
| Node.js | ✅ 已装 | v22 |
| npm | ✅ 已装 | v10 |
| Git | ✅ 已装 | 2.43 |
| Python3 | ✅ 已装 | 3.12 |
| Go | ✅ 已装 | 1.22 |

### 2.2 需要时再安装的工具

| 工具 | 用途 | 说明 |
|------|------|------|
| Expo CLI（`npx expo`）| 建 / 跑 React Native 项目 | 用 `npx` 免全局安装 |
| 项目 npm 依赖 | React Native / Expo SDK | `npm install` |
| Android SDK（可选）| 本地打 APK | 仅在需要云端打包 APK 时装 |

### 2.3 云端限制（重要）

- ❌ **没有 `/dev/kvm`** → **Android 模拟器无法运行**（模拟器需要硬件加速）。
- ❌ **没有 macOS / Xcode** → iOS 无法编译或运行。
- ✅ 因此云端做**可视化演示**的推荐方式是 **Expo 网页预览**（`npx expo start --web`），可在浏览器里渲染 App 界面并录屏。
- ✅ 若做原生 Android：云端能用 Android SDK + Gradle **编译出 APK**，但**看不到界面**（需下载到真机安装才能看）。

### 2.4 云端使用方式（Expo 路线）

```bash
# 建项目（首次）
npx create-expo-app@latest my-app
cd my-app

# 安装依赖
npm install

# 启动网页预览（云端可录屏演示）
npx expo start --web
```

## 3. ② 本地 Mac（Android + iOS 都能做）

Mac 是最全能的开发机：**Android 模拟器、iOS 模拟器、真机预览都能直接用**。

### 3.1 Expo / React Native 路线（推荐，最省事）

| 工具 | 必装? | 安装方式 | 用途 |
|------|-------|----------|------|
| **Node.js (LTS)** + npm | ✅ 必装 | 官网 / `brew install node` | 核心运行时 |
| **Watchman** | 可选 | `brew install watchman` | 加速文件监听 |
| **Xcode** | 想跑 iOS 模拟器才装 | App Store | iOS 模拟器 / iOS 打包 |
| **Android Studio** | 想跑 Android 模拟器才装 | 官网 | Android SDK + 模拟器 |

装好后：

```bash
npx expo start
# 按 i → 打开 iOS 模拟器
# 按 a → 打开 Android 模拟器
# 按 w → 打开网页预览
```

### 3.2 原生路线

- **原生 Android**：装 **Android Studio**（含 SDK、Gradle、模拟器）即可，Mac/Windows/Linux 都行。
- **原生 iOS**：必须 **Mac + Xcode**（这是 iOS 唯一的开发方式）。

### 3.3 手机（真机）预览

- 手机上**不装开发工具**，只需装 **Expo Go**（App Store / Google Play 免费）。
- 电脑 `npx expo start` 出二维码 → 手机 Expo Go 扫码 → **真机实时预览**，改代码自动刷新，连模拟器都不用。

### 3.4 各设备能力对照

| 设备 | 能否直接开发 | 备注 |
|------|-------------|------|
| **Mac 电脑** | ✅ Android + iOS 全能 | 装 Node（+ 想要模拟器再装 Xcode / Android Studio）|
| Windows / Linux 电脑 | ✅ 仅 Android + Expo | iOS 必须 Mac |
| **手机（Android/iOS）** | ✅ 装 Expo Go 预览 | 不装开发工具 |

## 5. 关于 Token（Cloud Agent 用量）

| 项目 | 花钱吗 | 花 Token 吗 |
|------|--------|-------------|
| 下载 / 安装 Expo、SDK、npm 包 | 免费（开源）| ❌ 下载动作本身不花 |
| 云端机器的网络流量 / 磁盘 | 含在环境里 | ❌ |
| **AI agent 执行命令、读输出、思考、回复** | —— | ✅ 计入 Cursor agent 用量 |

要点：
- **不是「下载工具」在烧 token**，而是「AI agent 运行、来回处理」在按用量计费。
- 命令输出越啰嗦、我读得越多，消耗越多 → 可用**安静模式安装**（如 `npm install --silent`）来节省。

## 6. 推荐工作流

1. **在 Cloud Agent（这里）**：用 Expo 搭好项目骨架，用网页预览跑起来 + 录屏验证。
2. **同步到本地 Mac**：`git pull` 后 `npm install` → `npx expo start`，Android/iOS 模拟器或真机（Expo Go）直接接着开发。
3. **要给别人用**：本地或 EAS 打包 Android APK / iOS IPA；要上架再注册对应商店开发者账号。

## 7. 环境限制备忘（当前 Cloud Agent）

- 架构：x86_64 Linux（非 macOS）。
- ❌ 无 `/dev/kvm` → 无法运行 Android / iOS 模拟器。
- ❌ 无 Xcode → 无法开发 iOS。
- ✅ 云端做可视化演示 → 用 **Expo 网页预览**。
