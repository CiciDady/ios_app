## 1. 产品定位

一款「**摆拍引导相机**」:相机预览上叠加**姿势引导**,并根据背景智能推荐好看的姿势、在人物摆到位时自动拍摄,帮助用户更容易出好片。

**核心价值(重点,不可回避的两个难点):**
1. **根据背景,随机选出「美的」姿势**。
2. **人物匹配姿势轮廓,达到阈值就自动拍摄**。

> 其余(轮廓叠加、倒计时快门、构图线等)是外围辅助功能。

## 3. 目标使用流程(用户视角)

```
① 打开相机预览
② 点「确定背景」→ 以当前取景为构图基准
③ 依据背景，随机推荐 5 个「和背景相配的好看姿势」缩略图
④ 点「换一批」重新随机 5 个；点某个 → 选中
⑤ 选中姿势的轮廓半透明叠加到预览（可调透明度/左右翻转/位置）+ 九宫格构图线
⑥ 人物按轮廓摆姿势 → 实时显示匹配度
⑦ 匹配度 ≥ 阈值且稳定 → 触发拍照（可选 2–10s 倒计时）
⑧ 保存到系统相册 + 结果预览（重拍/保存）
```

---

## 4. 核心功能 1:背景 → 推荐「美的」姿势

**定性:「美」靠「精选姿势库(每个都好看)」+「算法把背景匹配到合适姿势」,不去用算法计算美学。**

流水线:
```
① 背景理解：对取景帧做「场景识别」→ 标签(海边/街道/室内/落日/墙前/楼梯…)
             + 方向(竖/横) + 可选：留白/主体站位
② 匹配打分：在带标签的姿势库里，按 场景匹配度 + 构图/方向 打分
③ 加权随机：从高分候选随机抽 5 个（支持「换一批」）
```

**重大分叉(待定):背景理解放端侧还是云端**

| 方案 | 做法 | 优点 | 代价 |
|------|------|------|------|
| **端侧(推荐起步)** | 本地模型:ML Kit Image Labeling / 场景分类 | 免费、快、离线、隐私好 | 「融合」是近似(标签匹配) |
| 云端「智能模式」 | 低清背景缩略图传服务器,视觉大模型返回适配姿势标签 | 更懂背景、更接近「融合」 | 需后端 + 联网 + 调用成本 + 隐私授权 + 延迟 |

**建议**:MVP 先端侧;云端智能模式作为可开关增强项后加。

## 5. 核心功能 2:人物匹配轮廓 → 达阈值自动拍

```
每帧：vision-camera frame processor → 人体姿态检测(关键点)
      → 与「目标姿势关键点」算相似度(0–100%)
      → ≥阈值 且 稳定 N 帧 → 触发拍照(可选 2–10s 倒计时)
```

关键设计:
- **姿态检测模型(跨平台)**:ML Kit Pose Detection / MediaPipe Pose / MoveNet(TFLite);**动手前先验证选定具体库**。
- **相似度**:检测骨架与目标骨架都做**归一化**(去位置/大小,可选去旋转)→ 比较关节角度/位置 → 匹配百分比。
- **触发**:阈值(如 85%)+ **防抖**(稳定约 0.5–1s 才拍)。
- **UX**:实时匹配度进度条 / 轮廓由红变绿。
- **对姿势库要求**:每个姿势必须存**归一化关键点**(不只是轮廓图)。

## 7. 姿势库数据模型(草案)

每个姿势:
- `id`、`name`、`thumbnail`、`overlay`(轮廓图)
- `sceneTags`[]、`orientation`(portrait/landscape/square)、`subject`(single/couple/group)、`style` ← 功能 1
- **`keypoints`(归一化关键点)** ← 功能 2(**必需**)
- `matchThreshold`(每姿势可微调)、`anchor`/`defaultScale`(叠加位置与大小)

初期:内置 JSON + 素材;后期可云端下发更新。

## 8. 测试现实(重要约束)

- 两个核心功能全靠**实时相机 + 真人在镜头前**;**Cloud 云端无摄像头、无模拟器**,**无法在云端验证真实效果**。
- 云端能做:搭工程、写逻辑、用**离线样张**验证「姿态检测 + 相似度算法」、出 **APK / Dev Build**。
- **真实效果必须在真机上反复测**(装 Dev Build),实时 AI 相机功能需在真机上快速迭代。

## 9. 已定决策(2026-07-11,用户「继续开始工作」后按推荐默认拍板)

1. **功能 1 背景理解** → **端侧场景识别 + 标签匹配 + 加权随机**(离线、免费);云端智能推荐作为后期可开关增强。
2. **姿势库** → 先内置**占位姿势(带归一化关键点)**跑通完整流程,用户后续用真实素材替换。
3. **姿态检测** → **优先流畅实时**(轻量模型);精度后续再调。
4. **iOS** → 代码跨平台同源;**先安卓真机跑通**,iOS 随后验证。
5. **阈值/倒计时** → 默认匹配阈值 **85%**;达标后支持**可选 2–10s 倒计时**再拍(倒计时可关=达标即拍)。

> 这些是可调默认值,后续可随真机效果修改。
